## About

I am a developer from **Khulna, Bangladesh**, focused on turning ambitious ideas into practical, browser-first software. My work sits at the intersection of **full-stack engineering, experimental interfaces, networking, automation, and cybersecurity**.

I enjoy building tools that feel both capable and approachable: lightweight operating-system experiences in the browser, peer-to-peer utilities, media platforms, communication tools, and security-oriented systems for responsible testing. I am especially interested in the lower layers of the web—**WebAssembly, WebRTC, TypeScript, asynchronous Python, and browser APIs**—where thoughtful engineering can make complex technology feel simple.

> **Current direction:** building fast, secure, and imaginative web systems that are useful beyond the demo.

## What I Build

| Area | Focus |
| --- | --- |
| **Browser systems** | WebOS concepts, virtual machines, emulators, desktop-like interfaces, and browser runtimes. |
| **Security engineering** | Responsible WAF auditing, controlled load testing, network tooling, and security sandbox concepts. |
| **Real-time web** | Peer-to-peer file transfer, encrypted communication, streaming interfaces, and collaborative experiences. |
| **Developer tools** | High-speed utilities, automation workflows, experiments with WebAssembly, and performance-focused prototypes. |

## Engineering Principles

For security-related work, I value responsible testing, clear boundaries, and controlled environments. For product work, I value strong interaction design, readable code, and an experience that makes the underlying technology easier to understand.
