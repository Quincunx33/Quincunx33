## A little about me

I am a developer from **Khulna, Bangladesh**, building software that is ambitious in concept and practical in execution. My interests span **TypeScript, Python, real-time web applications, browser APIs, WebAssembly, automation, and responsible security research**.

I like taking difficult ideas—distributed file transfer, private communication, performance testing, interactive computer vision, or emulation—and turning them into interfaces that people can actually use. My approach is simple: keep the experience elegant, keep the implementation thoughtful, and keep learning in public.

> **My north star:** make complex technology feel clear, capable, and a little more exciting.
